# SolexPay (Demo)

**SolexPay** is a high-fidelity student fintech prototype built with Flutter. It demonstrates a premium, investor-ready mobile banking experience with a focus on "Campus Flex" branding and regulatory compliance.

## Key Features
- **Realistic Device Emulation:** Embedded iPhone 15 Pro (Titanium) frame for desktop demos.
- **Glassmorphic UI:** Custom `GlassCard` components optimized for both Mobile and Web performance.
- **Compliance-Ready:** Integrated CBN KYC Tiering (Level 1, 2, 3) and anti-fraud centers.
- **Financial Flows:** Robust P2P transfers, loan repayment breakdowns with E-signatures, and OPay-style bank selection.

## Tech Stack
- **Framework:** Flutter (Web/Mobile)
- **State Management:** Provider with optimized `context.select` patterns.
- **Navigation:** GoRouter for declarative routing.
- **Styling:** Custom Design System (Campus Flex) with physical realism.

## Getting Started
1. Clone the repository.
2. Run `flutter pub get`.
3. Launch with `flutter run -d chrome` or your preferred mobile emulator.
